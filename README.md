# Doomed BG Fix

Аддон к Doomed (doomedmatu) 0.4.7.x для Minecraft 1.20.1 / Forge 47.3+.

## Что делает

1. Полностью переделанная мини-игра ампутации (CutScreen):
   - послойный рез: кожа -> жир/фасция -> мышца -> КОСТЬ (0.34..0.66, сопротивление 4.5, как в оригинале) -> дальняя стенка;
   - кровотечение с первого движения, растёт по глубине; максимум при полном отделении остаётся ванильным (100 на культе);
   - рана создаётся как SURGICAL_INCISION, поэтому она ВСЕГДА глубокая и её можно зашить сразу, на любом этапе;
   - прогресс не сбрасывается при закрытии окна / смене слота / релоге: он лежит в capability игрока
     и уходит только вместе с регенерацией конечности;
   - дошёл до кости -> перелом; срок срастания пропорционален пропилу (пред-зачёт boneHealTicks),
     полный пропил = полный ванильный срок;
   - уже разорванная конечность начинает мини-игру покоцанной (CutMath.freeDepth);
   - ввод непрерывный (10 Гц + клиентское предсказание), без ванильных блокировок pending / 300 мс / чередования направлений;
   - жгут не обязателен, но UI честно предупреждает: жгут НИЖЕ линии реза не работает.
2. Фикс жгута: при потере конечности (performOn, самоампутация, dismember, necroticLoss, gibHead)
   жгут больше не исчезает - возвращается в инвентарь или падает на землю с тем же износом.


## Конфиг

config/doomedbgfix-common.toml: скорость пиления, множители крови/боли, скорость закрытия заброшенного реза,
твёрдость кости, анти-чит лимиты, enableRework (выключить = ванильная мини-игра), dropTourniquetOnLimbLoss.
